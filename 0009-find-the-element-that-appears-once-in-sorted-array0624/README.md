# Single Among Doubles in a Sorted

**Difficulty:** Medium

**GeeksforGeeks:** [View Problem](https://www.geeksforgeeks.org/problems/find-the-element-that-appears-once-in-sorted-array0624/1)

**Topics:** Searching, Divide and Conquer

## Problem Statement

Given a sorted array **arr[]**. Find the element that appears only**once**in the array. All other elements appear exactly **twice**.

**Examples:**

```text
Input: arr[] = [1, 1, 2, 2, 3, 3, 4, 50, 50, 65, 65]
Output: 4
Explanation: 4 is the only element that appears exactly once.
```

```text
Input: arr[] = [5]
Output: 5
```

```text
Input: arr[] = [1, 2, 2, 3, 3]
Output: 1
```

**Constraints:**
1 &le; arr.size() &le; 2 * 10^6
1 &le; arr[i] &le; 10^6
