# Rotate by 90 degree

**Difficulty:** Medium

**GeeksforGeeks:** [View Problem](https://www.geeksforgeeks.org/problems/rotate-by-90-degree-1587115621/1)

**Topics:** Matrix

## Problem Statement

Given a****square****matrix **mat**[][] of size **n x n**. The task is to rotate it by**90 degrees** in an**anti-clockwise** direction without using any extra space.

**Examples:**

```text
Input: mat[][] = [[0, 1, 2],
                [3, 4, 5],
                [6, 7, 8]]
Output: [[2, 5, 8],
        [1, 4, 7],
        [0, 3, 6]]
```

```text
Input: mat[][] = [[1, 2],
                [3, 4]]
Output: [[2, 4],
        [1, 3]]
```

**Constraints:**
1 &le; n &le; 10^2
0 &le; mat[i][j] &le; 10^3
